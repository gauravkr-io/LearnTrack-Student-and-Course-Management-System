# JVM Basics

## What is the JDK?

The Java Development Kit (JDK) is the full software development package used to build Java applications. It includes the compiler (`javac`), the runtime environment, and tools for packaging and debugging Java code.

## What is the JRE?

The Java Runtime Environment (JRE) contains the components needed to run Java programs, including the JVM and the core Java libraries. It does not include the compiler or other development tools.

## What is the JVM?

The Java Virtual Machine (JVM) is the engine that executes Java bytecode. It reads compiled `.class` files and performs the work of running the Java application on the host machine.

## What is bytecode?

Bytecode is the intermediate form produced by the Java compiler from source code. It is a platform-neutral representation that the JVM understands. When you compile `HelloWorld.java`, the JVM runs the generated bytecode rather than the original source file.

## What does “write once, run anywhere” mean?

"Write once, run anywhere" means that Java programs can be written one time and then run on any platform that has a compatible JVM. Because Java code is compiled into bytecode rather than machine-specific instructions, the same compiled program can execute on Windows, macOS, or Linux without changing the source.

This portability is possible because the JVM acts as a translation layer between the platform-neutral bytecode and the operating system or hardware. As long as a platform provides a Java Virtual Machine, the same Java application will behave consistently there.
